- Home
- About
- Experience
- Skills
- Projects
- Education
- Contact

- Scroll reveal animations
- Floating hero cards and animated artwork details
- Hover micro-interactions
- Animated skills/project visuals
- Project detail modal
- Active navigation
- User-provided hero image in `assets/girl-at-desk.png`

## Important
The hero image is the exact image supplied by the user and is stored locally in the site. No external image host is required.

## Free GitHub Pages publishing
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `Sumanpreet_Kaur_CV.pdf`, and the `assets` folder.
3. Open Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)`.
5. Save and wait for GitHub Pages to publish.

Before publishing, replace any placeholder project/social links with your real URLs.
